### Hi, I'm Riccardo 👋

I'm a test engineer in Switzerland working on precision laser measurement systems. My background is in power electronics hardware. My master's thesis was a 15 kW DC-DC converter, and I worked in automotive power electronics for a while before moving into test. These days I spend most of my time taking messy, exploratory testing and making it repeatable, automated, and measurable.

**Design it, build it, prove it.**

#### Open source

Under [Stokker Technologies](https://github.com/stokker-technologies) I build the tools I wish I'd had at the bench:

- **[Dokime](https://github.com/stokker-technologies/dokime)** runs repeatable engineering tests and keeps the evidence. You define test procedures in Rust, sweep them across operating conditions, capture live measurements, and get self-contained HTML reports anyone can open.
- **[Harmos](https://github.com/stokker-technologies/harmos)** is a composable Rust runtime for stateful engineering tools, with scoped undo, crash recovery, typed live data streams, and sandboxed WebAssembly plugins.

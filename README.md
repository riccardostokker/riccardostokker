### Hi, I'm Riccardo 👋

I bought my first Arduino at thirteen and never really recovered. Hardware is home turf, mostly power electronics: my master's thesis was a 15 kW DC-DC converter rigged up on the bench from scratch, and I stayed in automotive power electronics for a while after that. That pulled me into software, because you can't really design hardware anymore without writing the tools that do it (Rust for the engines, Python for the analysis).

These days I'm a test engineer on precision laser measurement systems. Mostly that means taking messy, exploratory testing and turning it into something repeatable, automated, and measurable. Half Italian, half Hungarian, living in Switzerland, so tidying chaos into clear steps comes with the territory.

#### Open Source

On the side I build the tools I wish I'd had at the bench. They live under [Stokker Technologies](https://github.com/stokker-technologies):

- **[Dokime](https://github.com/stokker-technologies/dokime)** runs repeatable engineering tests and keeps the evidence. You write the procedure in Rust, sweep it across operating conditions, capture live measurements, and get a self-contained HTML report that anyone can open without installing a thing.
- **[Harmos](https://github.com/stokker-technologies/harmos)** is the Rust runtime underneath it, for stateful engineering tools that need undo, crash recovery, typed live data streams, and sandboxed plugins.

Same pattern as my old graduation Tesla coil, just with fewer scorch marks.
